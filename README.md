🍛 Lucky Biryani Website (HTML & CSS)

        The Lucky Biryani Website is a clean, simple, and visually appealing restaurant webpage built using pure HTML and CSS. It showcases the flavors of Lucky Biryani with an attractive layout, smooth design, and beginner-friendly code structure.

🌟 Features 

        🍽️ Modern restaurant landing page
        🖼️ Beautiful hero section with biryani imagery
        📋 Menu section with featured biryani items
        🎨 Fully custom design using only CSS
        📱 Responsive layout for mobile and desktop
        ✨ Simple and easy-to-understand code

🛠️ Technologies Used

        HTML5 for structure
        CSS3 for styling and responsiveness
